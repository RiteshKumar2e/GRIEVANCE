# SYNTHETIC demo datasets

Generated by `backend/scripts/generate_synthetic_data.py` (seed 20261111). **These are not official HackFusion datasets.** All names, places, phone numbers and complaints are fictional. Every row is imported with `data_source = SYNTHETIC` and shown with a SYNTHETIC badge in the UI. Replace them through Admin → Datasets or `python -m app.cli import` once the official Category Master, Grievance History and Department Directory are available.
