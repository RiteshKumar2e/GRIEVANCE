# Offline evaluation suite

```bash
cd backend
python -m evals.run                                    # hashing embedder: fast, no model download
python -m evals.run --embedder sentence-transformers   # multilingual model (pip install -r requirements-ml.txt)
```

Each run creates a throw-away SQLite database, seeds the SYNTHETIC datasets, disables LLM calls and writes
`results/<embedder>.json` (full detail, including every error case) and `results/<embedder>.md` (summary).
No network access is needed after the embedding model is cached. `tests/test_evals.py` checks the metric
code and the SLA backtest's no-leakage property on every test run.

## Datasets

| File | Rows | What it tests | Labels |
| --- | --- | --- | --- |
| `datasets/intake.jsonl` | 52 | Category classification, language detection and sensitive-case routing in English, Hindi, Marathi, romanised Hindi, Marathi-English and mixed input, including a vague and a location-free complaint | Gold category and sensitivity |
| `datasets/injection.jsonl` | 23 | Prompt-injection detection: 13 attacks (9 the guard was written for, 4 paraphrases expected to be missed) and 10 benign complaints that use similar words ("ignore", "band kar do", "previous complaint") | injection true/false |
| `datasets/duplicates.jsonl` | 31 reports, 15 incidents | Same-incident reports across languages; hard negatives: a neighbouring locality with the same problem, the same lane with a different problem, near-identical wording 5 km away | Incident id |
| `data/synthetic/grievance_history.csv` | 720 | RAG corpus and SLA backtest | Category, created/resolved times |

**Provenance.** Every row in `datasets/` was written by the project author for this evaluation. None is a
real citizen complaint, and none was copied from the synthetic history used as the RAG corpus. The history
file is generated by `scripts/generate_synthetic_data.py` (seed 20261111).

**Change log.** `duplicates.jsonl` rows d28 to d31 (same-language duplicates) were added after the first
run showed that every positive pair was cross-language, which made same-language recall undefined. They
fill a coverage gap; no threshold or weight was changed in response to any result.

## Metrics and definitions

- **Intake**: accuracy of the deterministic rules classifier, which every request falls back to when the
  LLM is unavailable. The LLM path is not evaluated here, because it needs external API keys and is not
  reproducible offline.
- **Sensitive routing**: share of sensitive gold cases for which the real policy gate (`policy.evaluate`)
  requires human review, whatever category was predicted. The target is 100%.
- **Injection**: precision, recall, false alarms and misses of `INJECTION_PATTERNS`.
- **Duplicates**: precision, recall, F1, false-positive and false-negative rate of `score_pair` at the
  configured thresholds over every same-department pair (the candidate set production compares). The
  threshold sweep is diagnostic only.
- **RAG**: P@5, Hit@1 and MRR. Relevance is a proxy: a precedent counts as relevant when it has the query's
  gold category. There are no human relevance judgements. Reported both unfiltered (embedder quality) and
  in the production configuration (category to department to all widening, using the predicted category).
- **SLA**: chronological rolling-origin backtest. Cases are ordered by creation time; the last 30% are test
  cases, and each is predicted from cases resolved **before it was filed** (`leakage_violations` counts any
  breach of that rule). Reported: ECE (10 equal-width bins), Brier score, AUC, log loss and the 0.6 alert
  threshold, against two baselines (historical base rate, constant 0.3). Rows the generator clamped to its
  "now" (right-censored) are excluded and counted.

## Limitations

- Small, author-written sets: one or two errors move a per-language number by 7 to 33 points. Treat
  per-language figures as indicative.
- The datasets were written by the same person who wrote the rules and the injection patterns, so the
  intake and injection numbers are optimistic regression checks, not unbiased estimates.
- The SLA history is synthetic. Its resolution times come from a per-category log-normal distribution that
  does not depend on time, urgency or load, so the backtest shows whether the estimator recovers that
  distribution. It is not evidence of real-world accuracy.
- The RAG relevance proxy rewards same-category retrieval, not whether the precedent's action would help.
